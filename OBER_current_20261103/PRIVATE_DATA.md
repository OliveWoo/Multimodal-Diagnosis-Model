# 公開快照與私有重播資料

## 本次只發布

- 目前規則／QC、重跑比較、保守離線實驗的程式碼與提示詞。
- 執行時必要的來源／檢索／病例反思／訊號／A1依賴。
- 合成單元測試、研究方法、版本狀態與聚合統計。
- 原樣來源檔案的相對路徑與SHA256；不含本地執行回應ID或資料雜湊清單。

## 本次不發布

- 原始病歷、病史、檢驗資料、採檢／病人對照表、逐例醫院答案。
- `runs/`、來源資料包、逐例預測／報告、文獻配對病例資料與任何API請求／回應。
- `.env`、`env.env`、token、帳號憑證、私鑰。
- 原始Excel、壓縮檔、PDF、影像及其他附件。

公開倉庫無法只靠去識別化編號就保證臨床明細可公開，因此本次不把任何逐例執行資料一起上傳。

## 什麼能直接重現

README中的三組合成測試可以在此code-only快照直接執行；它們檢查固定規則、文章分流、來源限制、比較映射和核心／細節拆分，不需API或病人資料。

49例聚合分數不能從公開快照單獨重算。原研究需要：上游v7來源、時間／檢體對應、固定病例事實、原G/T判讀、A1抽取、公開文章快照、歷次凍結清單，以及最後才讀取的醫院答案。

這些產物留在原私有工作區。原凍結清單包含原絕對路徑與依賴雜湊；不能任意搬動、重新生成清單，然後宣稱仍是同一個凍結實驗。公開snapshot沒有修改這些研究契約，也沒有為全新輸入提供完成驗證的通用adapter。

不要把私有資料複製進本目錄後`git add .`。若未來需要新的資料轉接或可攜式重播，應建立新版本、明確說明來源映射／雜湊契約的變化，而不是偷偷改舊程式。
