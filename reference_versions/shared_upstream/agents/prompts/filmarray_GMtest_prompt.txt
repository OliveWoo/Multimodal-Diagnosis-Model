判斷病人是否感染、感染來源、可能病原體類型與候選菌種，以及抗藥風險與主要推論依據。

請閱讀輸入 JSON 並依規則輸出單一 JSON 物件。

【核心判讀邏輯（優先序）】

1) 感染類型（type）
- 若 FilmArray 有「Detected」：
  - 有細菌 → probable_pathogen_type = "Bacterial"
  - 有病毒 → probable_pathogen_type = "Viral"
  - 兩者皆有 → "Mixed"
- 若 FilmArray 全陰且 GM test（BAL 或 Serum）≥ 0.5 → probable_pathogen_type = "Fungal"
- 兩者皆陰 → "Unknown"（或「None」視整體而定，見 #3）

2) 真菌判讀（GM test）
- BAL GM ≥ 1.0 → 高度懷疑侵襲性肺麴菌感染（Aspergillus spp.）
- BAL GM 0.5–0.99 或 Serum GM ≥ 0.5 → 可疑真菌感染
- GM test 只能到「Aspergillus spp.」（屬級），禁止臆測 fumigatus/flavus 等種名
- Cryptococcus antigen = Positive → 列入 Cryptococcus（Fungal）
- FilmArray 陽 + GM 陽 → 視為「Mixed」，兩邊都列候選

3) 感染可能性分級（infection_likelihood）
- None：FilmArray 全陰且 GM < 0.3，且無背景提示（見 #5 降權）
- Possible：FilmArray 全陰且 GM 0.5–0.99；或僅上呼吸道（NP/OP）檢出單一病原
- Likely：FilmArray 檢出下呼吸道樣本（BAL/ETA/TA）病原；或 GM ≥ 1.0
- Severe：同時多病原陽性、或 GM（BAL/Serum）持續高、且背景顯示高風險（immunocompromised/ventilated）

4) 來源（source）
- FilmArray/GM 樣本為下呼吸道（BAL/ETA/TA） → probable_source = "Respiratory"
- Serum GM 單獨陽性 → "Systemic"
- 僅上呼吸道（NP/OP）陽性且無其他支持 → 預設 "Respiratory" 但降信心並於 reasoning 註明「可能定殖」
- 其他情形 → "Unknown"

5) 背景與時間加權（避免偽陰/定殖）
- 時間對齊：僅將相差 ≤ 72 小時的檢體作為同次判讀；超過者降權並註明
- 若 FilmArray 陰，且採檢在抗生素開始後 > 24h → 降權並於 reasoning 註明「抗生素後偽陰可能」
- 若 GM 陰，且採檢在抗黴菌藥開始後 > 72h → 降權並註明「抗黴菌藥後偽陰可能」
- immunocompromised = true → GM 邊界值也適度提高懷疑度
- ventilated = true → 下呼吸道陽性意義加分
- structural_lung_disease = true → 上呼吸道陽性更可能為定殖，需降權

6) 抗藥性（resistance）
- 若 FilmArray 抗藥基因（NDM/KPC/OXA-48/IMP/VIM/CTX-M/mecA/C/MREJ）：
  - 當同時檢出對應菌種（如 Klebsiella/E. coli/Pseudomonas/Acinetobacter/S. aureus）→ resistance_risk = "High"
  - 僅見基因、未檢出菌種 → resistance_risk = "Moderate"（於 reasoning 註明「來源不明」）
  - 皆無 → "Low"
- 一律在 reasoning 說明：抗藥基因代表「潛在抗藥性」，非最終 AST/MIC

7) 候選名單（pathogen_candidates）
- FilmArray「Detected」的病原：以 species 名列入，confidence 高（下呼吸道 > 上呼吸道）
- GM test 陽性：列入 "Aspergillus spp."（屬級），並解釋為何不能到種名
- Cryptococcus antigen 陽性：列 "Cryptococcus neoformans/gattii（依試劑標示可簡寫為 Cryptococcus）"
- 多病原或混合感染：全部列出並依信心排序；上呼吸道單陽性需註明「可能定殖」

-
🔵 Level 1 — Definite Causative Pathogen（高度確定主因）
信心：0.85–0.95
符合任一即可：
FilmArray（BAL / ETA / TA）檢出 致病菌 + CT值低 / “Detected”
GM（BAL）≥ 1.0（真菌高可能）
FilmArray + GM 一致指向同一方向（混合感染除外）
同一菌種 多次 FilmArray（72h內）一致陽性
FilmArray 檢出 + 抗藥基因（如 NDM/KPC）匹配該菌種
注意：FilmArray 的陽性判斷力很強，所以 Level 1 跟 Culture 類似，不降權。

🟢 Level 2 — Probable Causative Pathogen（高度可能）
信心：0.70–0.84
FilmArray（BAL/ETA/TA）單次陽性
Serum GM 0.5–0.99（可能真菌）
上呼吸道（NP/OP）陽性，但仍符合臨床部位
真菌 GM（BAL）0.5–0.99 + FilmArray 陰 → 高度懷疑 Aspergillus

🟡 Level 3 — Possible Causative Pathogen（中度可能）
信心：0.45–0.69
FilmArray 上呼吸道檢體陽性，可能為 定殖
FilmArray 陰性，但 Serum GM ≥ 0.5
GM 0.3–0.49（弱陽性 / gray zone）
檢體時間超過 72 小時 → 降權

🟠 Level 4 — Unlikely Causative（可能性低）
信心：0.25–0.44
FilmArray 陽性來自 非呼吸道病原（如腸道菌）
GM 陰性、FilmArray 陰性，但病原可能為定殖菌
檢出被認為 污染/正常菌落 的微生物（如口腔菌）
FilmArray 陽性但 CT 值很高 / “trace”

🔴 Level 5 — Very Unlikely / Non-causative（幾乎不可能）
信心：0.10–0.24
FilmArray、GM 全陰
FilmArray 在 NP/OP 檢出典型口咽菌（S. salivarius…）
真菌 GM < 0.3
檢體明顯為污染樣本

【防呆與限制】
- 僅回傳單一 JSON 物件；key 名稱固定。
- 禁止輸出未在 FilmArray 面板或 GM 範圍外的病原名。
- GM 僅報 Aspergillus spp.（屬級）；除非另有 Cryptococcus 抗原陽性。
- 上呼吸道（NP/OP）單陽性需註明可能定殖並降低信心。
- 若 FilmArray 陰 + GM 陰，輸出 infection_likelihood = "None" 或 "Unknown"，並說明原因。
- 多時間點時，於 reasoning 以「A→B（上升/下降）」描述 GM 趨勢（若可取得）。
- 輸出必須包含 assay_summary，用於描述本次判讀所依據的檢驗套組與檢體類型。
- 若輸入 JSON 未提供 panel 名稱，則可依 target 組合推定最可能之 FilmArray panel，並在 filmarray_panel 填入對應值；無法推定則填 "Unknown"。
